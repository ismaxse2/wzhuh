# Wzhuh

Wzhuh — приложение для изучения английских слов. Личный словарь, история ответов и настройки хранятся локально в браузере.

## Механика

- В каталоге тематические наборы слов. Можно добавлять отдельные слова или набор целиком. Общие слова связаны через `vocabularyId` и имеют общий прогресс; разные значения могут изучаться отдельно.
- На главной можно подобрать случайные слова для изучения из словаря. Ручной выбор слов доступен в словаре. Стандартное количество слов в уроке задаётся в настройках и не ограничивает число уроков в день.
- Урок перемежает слова и проводит каждое через знакомство, узнавание перевода, обратный перевод, конструктор по буквам, написание и контекст. Если конструктор неприменим, он пропускается. Слово становится изученным после всех применимых стадий.
- В контексте предлагаются четыре заранее подготовленных варианта; Письменная стадия принимает явно заданные альтернативные ответы, включая варианты написания и проверенные синонимы.
- Правильный ответ сразу открывает следующее задание. Ошибочное задание возвращается в очередь без ожидания; успешные задания сохраняются.
- Активный урок восстанавливается после перезагрузки. Его можно завершить досрочно: ответы и полностью изученные слова сохраняются, частичное прохождение не считается полным уроком.
- Изученные слова можно повторять сразу. Интервалы 14 → 30 → 60 → 120 дней служат рекомендациями; ошибки в полном повторном уроке возвращают интервал к 14 дням. Кнопка «Повторять» на главной выбирает слова с приоритетом наступивших рекомендаций и давности повторения.
- В словаре доступны поиск, фильтры по набору и статусу, ручная смена статуса и выбор слов для урока. В профиле — статистика и настройки.
- Автоматическое произношение включается в настройках.

При очистке данных браузера прогресс удаляется.

## Стек

React 19, TypeScript, Vite 7, Tailwind CSS 4, React Router 7, Lucide, локальный Inter. Хранение — localStorage; озвучивание — Web Speech API. Тесты — Vitest и Testing Library. Качество кода — ESLint с `simple-import-sort` и Prettier.

Проект организован по FSD lite: `app` собирает приложение, `pages` — страницы, `features` — действия пользователя, `entities` — предметную модель, `shared` — общий UI, функции и токены.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Проверки

```bash
npm run test          # тесты механики, данных, интерфейса и границ архитектуры
npm run test:watch    # тесты в режиме наблюдения
npm run lint          # ESLint, включая порядок импортов и экспортов
npm run lint:fix      # автоматические исправления ESLint
npm run format:check  # проверка форматирования
npm run format        # форматирование Prettier
npm run build         # проверка TypeScript и производственная сборка
```
